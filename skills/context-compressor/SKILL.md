# Context Compressor

Create a compact working brief that preserves what later work must not rediscover.

## Method

1. Establish the source set and audience; do not silently treat a partial set as complete.
2. Separate verified facts, decisions, constraints, unresolved questions, and next actions.
3. Preserve exact identifiers, dates, paths, commands, metrics, and citations when they determine correctness.
4. Remove repetition and low-value examples. Never convert uncertainty into fact.

## Output

Use a short purpose statement, then `Current state`, `Decisions and constraints`, `Evidence`, `Open questions`, and `Next actions` only when material. Attribute claims to source files or links. End with omissions or uncertainty that could affect the next decision.
