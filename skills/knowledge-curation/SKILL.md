# Knowledge Curation

Improve retrieval and trustworthiness while preserving provenance and intent.

## Workflow

1. Audit the target collection for ownership, purpose, freshness, duplicates, broken links, conflicting statements, and naming drift.
2. Propose the smallest architecture that supports retrieval: stable names, clear locations, useful metadata, and explicit links.
3. Preserve source provenance and dates. Mark uncertain, superseded, or conflicting material instead of silently merging it.
4. Make only requested, reversible changes; do not delete or broadly reorganize material without confirmation.

## Verification

Check edited links, discoverability by likely search terms, duplicate handling, and whether a new reader can identify the canonical source. Report changed paths, unresolved conflicts, and a review cadence recommendation.
