# Document Editing

Make the requested document change without silently changing its meaning or scope.

## Before editing

1. Identify the source file, intended output path, document format, and exact change scope. Treat a request to propose wording as a draft unless the user asks to apply it.
2. Preserve the original unless the user explicitly authorizes an in-place edit. For structured formats, inspect the rendered result when formatting or layout matters.
3. Keep existing terminology, heading hierarchy, numbering, tables, links, citations, and change-tracking conventions unless the request changes them.

## Editing workflow

1. Apply only the requested additions, removals, rewrites, or reorganization. Mark assumptions and unresolved source conflicts rather than inventing content.
2. Retain unaffected sections and repair internal references, numbering, tables of contents, and links when the edit changes them.
3. For factual, legal, financial, medical, or policy content, do not alter claims beyond the authorized edit without confirmation or supplied evidence.

## Verification and handoff

1. Confirm the output opens in its target format and that the intended edits appear in the correct locations.
2. Check for accidental loss of headings, tables, citations, comments, metadata, or adjacent text; compare before and after when the change is material.
3. Report the output path, the substantive changes made, and any formatting limitations, assumptions, or unresolved items.
