# PPTX Editing

Make the requested slide changes without breaking the presentation's visual hierarchy.

## Preflight

1. Confirm the target slides, desired output path, aspect ratio, template constraints, and whether notes, media, animations, embedded objects, or linked charts must survive.
2. Preserve the original and inspect representative slides before editing. Use a PPTX-aware tool only for elements it supports; retain the native application workflow for unsupported features.

## Edit and verify

1. Reuse the presentation's masters, theme, layouts, spacing, and typography unless the request changes them. Do not replace a designed slide with plain text boxes merely to make an edit easier.
2. Keep visual content editable where practical and preserve source attribution for supplied images, charts, and quotations.
3. Reopen the generated file and render or inspect every changed slide. Check clipping, overflow, overlaps, line breaks, contrast, slide order, notes, and links.

## Limits

Treat animations, transitions, SmartArt, complex embedded charts, and OLE objects as fidelity-sensitive. If the toolchain cannot preserve one, stop before destructive overwrite and provide an alternative.
